RELAY vs. MOSFET
------------------
Relay needs a flyback diode (diode in reverse bias mode) that creates a grounding loop when dI/dt -> -infinity, therefore V_coil spikes and reverses polarity, damaging the relay
	Diode should be specced @ ____ ("Schotkey Diode")
JQC-3F 5VDC -> 28VDC, 10A is not enough for the estimated load of 15A maximum (I_stall*6)

MOSFET
-------
IRF4905 is rated for:
I_D = -74A (current flow from load to drain/drain to source)
V_GS = +/- 20V (range of gate operation)
V_GS_th = -2.0V (MOSFET turns on to some degree)
V_(BR)_DSS = -55V (maximum voltage that can be applied between the drain and source without damaging parts)
R_DS = .02 ohms (resistance of drain when turned on at certain voltage)

The 10k pull up and 100 ohm resistor form a voltage divider because the gate takes on no current:

V = IR, R = 10k + 100 ohm = 10.1k ohm, V_ss = 7.4V -> I = V/R = 7.4 / 10.1k = 0.733mA

V_R_10k = I*R(10k) = 0.733mA * 10k ohms = 7.33V drop across R 10k

V_G = V_SS - V_R_10k = 7.4V - 7.33V = 0.07V 

V_GSS = V_G - V_SS = 0.07V - 7.4V = -7.33V -> current may now flow from Source to Drain

Battery Sizing
---------------
Energy = current rating * time 
	ex. 10A = 10A * 1000mA /A = 10000mA, at 1 hour = 10000mA * hr = 10000mAh battery
2S LiPo:

V_cell = 3.7V
N_cells = 2

I_average_robot = I_leg*num_leg + I_aruduino_and_periph = 1.5A * 6 + 1A = 10A = 10000mA
1 hour usage time at nominal current draw = 1 hr * 10000mA = 10000mAh 2S LiPo Battery

Voltage Divider for Battery read
---------------------------------
Use analog read on analog pin to determine battery percentage. Use voltage divider to step voltage down and read. Make sure voltage has a buffer in case LiPo 2S battery is greater than 8.4V at full charge

Choose:
R2 = 10000 ohms
V_s = 8.4V
V_2 = 4.7V (padding)

V_2 = V_s (R2) / (R1+R2) -> R2 = ~7800 ohms

V_ref = 5.0V
N = 10
ADC_Max = 2^N - 1 = 1023

ADC value = V_in/V_ref * ADC Max
V_in = ADC / ADC_Max * V_ref (voltage from 0-5V)

V_s = V_2 * (R1 + R2) / R2 (voltage from 0-8.4V)

Percent = V_s / V_total

NRF Module
-----------
NRF has 7 pins total:
Vcc (3v3)
GND
5 of which are IO:
CE (chip enable)
CSN (chip selection)
SCK (serial clock)
MOSI (master out slave in)
MISO (master in slave out)

NRF uses SPI to communicate, Arduino 2560 mega dedicates SPI to certain pins:
MISO: D50
MOSI: D51
SCK: D52
SS: D53 -> look into this more


I_LEDs
-------
Powered by analog pins or 3v3 staight up
220 ohm - 500 ohm resistance gives I = V/R = 3.3 / 220, 3.3 / 500 = [15mA, 6.6mA]

RD: Low power
GN: BD on
BU: NRF Controller Connected

joysticks
----------
joysticks have 4 pins purely for mechanical fastening (large rectangular pattern)
button simply pulls the digital input to ground, so need PU resistor on the associated DI

joystick POT
--------------
2 pots 
upper/left POT pin is power pin
	power needs to be 3v3 because esp32 adc expects 0-3v3, not 5v
lower/right POT pin is GND
center pin is analog output

-------
linear voltage regulator module that has adjustable output (via potentiometer)
will be mounted from 4-single pin male headers (instead of standoffs/actually adding the IC to the board)
