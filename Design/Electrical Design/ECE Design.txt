RELAY vs. MOSFET
------------------
Relay needs a flyback diode (diode in reverse bias mode) that creates a grounding loop when dI/dt -> -infinity, therefore V_coil spikes and reverses polarity, damaging the relay
	Diode should be specced @ ____

MOSFET
-------
IRF4905 is rated for:
I_D = -74A (current flow from load to drain/drain to source)
V_GS = +/- 20V (range of gate operation)
V_GS_th = -2.0V (MOSFET turns on to some degree)
V_(BR)_DSS = -55V (maximum voltage that can be applied between the drain and source without damaging parts)
R_DS = .02 ohms (resistance of drain when turned on at certain voltage)

Battery Sizing
---------------
Energy = current rating * time 
	ex. 10A = 10A * 1000mA /A = 10000mA, at 1 hour = 10000mA * hr = 10000mAh battery
2S LiPo:
V_full_Charge = 8.4V
V_nominal = 7.4V
V_depleted = 6.0V
V_cell = 3.7V
N_cells = 2
Cell_Connection = series
V_nominal = N_cells * V_cell = 2*3.7 = 7.4V

I_average_robot = I_leg*num_leg + I_aruduino_and_periph = 1.5A * 6 + 1A = 10A = 10000mA
1 hour usage time at nominal current draw = 1 hr * 10000mA = 10000mAh 2S LiPo Battery
Worse case: I_max = 20A = 20000mA-> T = 10000mAh / 20000mA = 30 minutes of run time

Voltage Divider for Battery read
---------------------------------
Use analog read on analog pin to determine battery percentage. Use voltage divider to step voltage down and read. Make sure voltage has a buffer in case LiPo 2S battery is greater than 8.4V at full charge

Choose:
R2 = 10000 ohms
V_s = 8.4V
V_2 = 4.7V (padding)

V_2 = V_s (R2) / (R1+R2) -> R2 = ~7800 ohms

V_ref = 5.0V
N = 10
ADC_Max = 2^N - 1 = 1023

ADC value = V_in/V_ref * ADC Max
V_in = ADC / ADC_Max * V_ref (voltage from 0-5V)

V_s = V_2 * (R1 + R2) / R2 (voltage from 0-8.4V)

Percent = V_s / V_total
